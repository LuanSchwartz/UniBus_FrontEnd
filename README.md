## 📌 Sobre o projeto

O UniBus FrontEnd é a interface do sistema UniBus, responsável por fornecer uma experiência moderna e amigável para os usuários interagirem com a aplicação.

## 🚀 Tecnologias

- React
- TypeScript
- JavaScript
- Yarn
- Design System @nexpy/design-system
